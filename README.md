# tts · YouTube Auto Uploader 안내 사이트

개인용 YouTube 업로더의 소개와 개인정보처리방침을 제공하는 정적 사이트입니다.
업로더 실행 코드, 영상, 인증키, 토큰은 이 저장소에 포함하지 않습니다.

- 소개: https://miroqaan.github.io/youtube-uploader-info/
- 개인정보처리방침: https://miroqaan.github.io/youtube-uploader-info/privacy.html
- 게시 소스: `main` 브랜치의 `/docs`
- 검사: `node test-site.cjs`

Google OAuth 동의 화면에 설정된 이름인 `tts`와 도구 이름을 함께 표시합니다.
이 사이트를 게시한 사실이 Google OAuth 검증 또는 YouTube API 감사를 통과했다는 의미는 아닙니다.
개인정보처리방침은 실제 도구의 데이터 처리 변경 시 함께 갱신해야 합니다.
