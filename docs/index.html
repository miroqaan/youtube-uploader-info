YouTube Auto Uploader는 지정한 폴더의 영상과 썸네일을 연결된 YouTube 채널에 업로드하는 개인용 프로그램입니다.

이 사이트는 도구의 기능과 데이터 처리 방식을 설명하는 안내 페이지입니다. 웹 업로드 서비스가 아니며, 회원가입이나 Google 로그인을 제공하지 않습니다.

기능

업로드에 필요한 작업만

01

영상과 썸네일 전송

사용자가 지정한 로컬 폴더의 영상, 선택한 썸네일과 제목·설명·태그를 YouTube Data API로 전송합니다.

02

게시 설정 적용

공개 범위, 예약 시각, 아동용 여부 등의 설정을 적용합니다. 기본 공개 범위는 비공개이며, 실제 게시는 YouTube의 정책과 제한을 따릅니다.

03

로컬에서 결과 확인

업로드 결과와 실행 로그를 컴퓨터에 기록합니다. 한 번 실행하거나, 사용자가 실행한 동안 지정 폴더를 확인하는 방식으로 사용할 수 있습니다.
